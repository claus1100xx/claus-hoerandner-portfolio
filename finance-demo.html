How this demo works

This agent simulation recognizes supported finance questions and runs defined calculations against a fictional ledger. It does not use a language model. Answers, charts, and CSV exports use the same underlying rows. Variance drivers show arithmetic contributions, not verified business causes. A production implementation would connect a language model to approved data sources, access controls, and governed metric definitions.
